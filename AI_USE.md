# AI Use Disclosure

Before starting this project, I went through the class slides and course materials to understand the concepts and requirements of the assignment. I started the implementation myself after reviewing those materials.

While working on the code, I used Claude mainly as a debugging and learning support tool. When I found bugs in my code, I used AI to help me understand what was causing the problem and how I could debug it. I did not use AI to replace the implementation work.

When I got stuck while working on a part of the assignment, I sometimes used AI to give me a hint about the next step instead of asking it to complete the problem for me.

There were also times when I had a gap in my understanding of something from an earlier part of the assignment. In those cases, I used AI to explain the earlier concept so I could understand it before continuing with the current part like sometimes its hard to understand things in engllish so I asked it to translate it to my language so that I get better understanding.

I reviewed the suggestions, made the changes myself, and tested my code to make sure I understood how it worked.

## AI Tool Used
- Google Gemini (for translation mostly and explanation of material)
- Claude (debugging and hints if got stuck)

## Main Uses

- Debugging bugs in my own code
- Understanding error messages and unexpected behavior
- Getting hints when I was stuck
- Reviewing concepts from earlier parts of the assignment
- Clarifying concepts from the class materials

Overall, AI was used as a learning and debugging aid, while the implementation and testing of the project were completed by me :)
